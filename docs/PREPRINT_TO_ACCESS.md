# Submission path

1. **Polish draft** in `manuscript/main.tex` (IEEEtran journal layout).
2. **Post preprint** (arXiv cs.AI / cs.NE, or TechRxiv) with this GitHub URL and CC BY aggregates.
3. **Before IEEE Access:** download official Access LaTeX zip via IEEE Template Selector; see `manuscript/TEMPLATE_NOTES.md`.
4. **Access claim:** protocol + NHANES→input documentation + existing-algorithm comparison (no new solver).
5. Cite the preprint DOI in the Access cover letter if required.
